# MI-3 歌词逐字动画（YRC 解析 + LyricTimeline + 逐帧驱动 + 逐字动画）实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让搜到 / 正在播的歌显示**跟得上、不顿**的逐字歌词动画，并支持译文 / 罗马音开关与点歌词行跳转。

**Architecture:** 歌词分三层。**解析层**（`lyric/`，纯 Kotlin、可单测）：把网易云返回的原始文本（新版 JSON 行 + 经典 YRC + 经典 LRC 三种格式混排）解析成 `LyricTimeline`——每行拆到每个字自己的时间区间，并用"最近时间戳"把译文 / 罗马音对齐到行上。**取词层**（`source/netease/`）：`getLyric` 走与搜索 / 取流同款 eapi 签名请求 `/api/song/lyric/v1`。**渲染层**（`ui/lyric/`）：用 `withFrameNanos` 建**逐帧时钟**，每帧读一次 ExoPlayer 的真实播放位置（毫秒精度），据此对每个字的"填充进度"做插值——**绝不用 250ms 的状态回调**（那会明显阶跃，是"惊艳"与"廉价"的分界线）。逐字填充用"暗底 + 亮字裁剪"实现：每个词画两遍文字，亮色那份用 `clipRect(right = width * progress)` 由左向右揭开。

**Tech Stack:** 沿用 MI-1 / MI-2（Kotlin · Compose BOM 2026.09.00 · AGP 9.4.1 · Gradle 9.8.1 · OkHttp 5.5.0 · Gson 2.11.0 · AndroidX Media3 1.11.1 · JUnit 4 · minSdk 26 / targetSdk 36 / compileSdk 37）。本里程碑**不新增依赖**。

### 1.1 歌词端点（**关键结论**）

| 项 | 值 |
|---|---|
| 方法 / 域名 | `POST https://interfacepc.music.163.com` |
| uri | `/api/song/lyric/v1` → 实际 URL 为 `/eapi/song/lyric/v1` |
| 加密方式 | **eapi（与 MI-1 / MI-2 完全相同）**，无需新增加密代码 |
| 需要登录吗 | **不需要**。匿名态即可拿到全文歌词（含 YRC） |
| 请求 JSON | `{"id":<songId>,"cp":false,"tv":0,"lv":0,"rv":0,"kv":0,"yv":0,"ytv":0,"yrv":0,"e_r":false,"header":{...}}` |
| `id` | **数字**（不是字符串，也不是数组——和取流的 `ids` 不同） |
| 响应 | 明文 JSON（`e_r=false`），无需解密 |

### 1.2 响应形态（实测）

```json
{"code":200,"sgc":true,"sfy":false,"qfy":false,
 "lrc":{"version":29,"lyric":"..."},
 "klyric":{"version":0,"lyric":null},
 "tlyric":{"version":0,"lyric":null},
 "romalrc":{"version":0,"lyric":null},
 "yrc":{"version":29,"lyric":"..."},
 "lyricUser":{...}}
```

| 字段 | 含义 |
|---|---|
| `lrc.lyric` | 逐行歌词（格式见 §1.3） |
| `yrc.lyric` | **逐字歌词**（格式见 §1.3）。**可能为空字符串**（该歌没有逐字数据）→ 必须降级用 `lrc` |
| `tlyric.lyric` | 译文（纯经典 LRC，可能为空字符串） |
| `romalrc.lyric` | 罗马音（纯经典 LRC，可能为空字符串） |
| `klyric.lyric` | 卡拉OK 歌词，实测几乎总为空 → **不用** |

### 1.3 三种行格式混排（**最容易踩的坑**）

`lrc.lyric` 与 `yrc.lyric` 都可能是**混合格式**：开头若干行是新版 JSON 行（元信息/credits），其余行是经典格式。实测样本（id=5257138「屋顶」）逐行如下：

```
{"t":0,"c":[{"tx":"作曲: "},{"tx":"周杰伦","li":"http://...","or":"orpheus://..."}]}
{"t":1000,"c":[{"tx":"作词: "},{"tx":"周杰伦"}]}
{"t":2000,"c":[{"tx":"编曲: "},{"tx":"屠颖"}]}
[24080,5080](24080,280,0)半(24360,210,0)夜(24570,560,0)睡(25130,300,0)不(25430,350,0)着(25780,950,0)觉
[29520,7750](29520,290,0)只(29810,400,0)好(30210,360,0)到(30570,350,0)屋(30920,300,0)顶...
```

**格式 A（新版 JSON 行）**：`{"t":<起始ms>,"c":[{"tx":"<文本>"},...]}`。
- 文本 = 所有 `c[].tx` 顺序拼接。
- `li`（图片链接）、`or`（跳转链接）等字段**忽略**。
- 实测这些行**没有逐字时间**（`c[]` 里没有内层 `t`），只做整行时间。

**格式 B（经典 YRC，逐字）**：`[行起始ms,行时长ms](字起始ms,字时长ms,0)<文本>(字起始ms,字时长ms,0)<文本>…`
- 行头是 `[a,b]`（**两个**数字）；每个字头是 `(a,b,c)`（**三个**数字，第三个恒为 0）。
- 文本紧跟字头之后，**无分隔符**，直接拼到下一个 `(` 之前。
- 文本里可能含空格（实测「浮沉随浪 只记今朝」里 `浪 ` 后带一个空格），**必须原样保留**——那是词间空格。
- 兼容：解析时行头与字头的第三个数字**可缺省**（有的数据只给两个）。

**格式 C（经典 LRC，逐行）**：`[mm:ss.xxx]<文本>`。
- 秒的小数位可能是 1~3 位（`[00:25.083]` / `[00:25.08]` / `[00:25]`），要按位数换算成毫秒。
- 一行可能有**多个时间标签**：`[00:01.000][01:20.000]<文本>` → 拆成两行。
- **元信息标签**（实测译文里出现 `[by:伤感咩吖]`）：`[标签:值]`，标签是字母 → 跳过；其中 `[offset:±ms]` 要**整体平移所有行时间**（本里程碑按"所有行时间减去 offset"处理）。
- `tlyric` / `romalrc` 是**纯**格式 C（不会混 JSON 行，但可能有 `[by:]`）。

### 1.4 译文 / 罗马音如何对齐到主歌词行（实测）

`tlyric` / `romalrc` 的行时间与 YRC 行时间**不精确相等**，实测相差 **±10~50ms**：

```
yrc 行时间戳前 8 : 29860, 33610, 37810, 41480, 46220, 54000, 61560, 65490
tlyric 行时间戳  : 29850, 33590, 37810, 41530, 46230, 54000, 61570, 65480
romalrc 行时间戳 : 29850, 33590, 37810, 41530, 46230, 54000, 61570, 65480
```

→ **对齐策略：对每一主行，取"起始时间最近"的译文/罗马音行，且距离须 ≤ 容差（取 600ms 留足余量）**，否则该行的译文/罗马音为 `null`（JSON credits 行因为时间在 0~3000ms，译文在 29850ms 起，天然对不上 → null，正确）。

### 1.5 无逐字数据的降级（实测）

大量歌曲 `yrc.lyric` 为空 → 只能用 `lrc.lyric` 做**整行高亮**（设计文档 §5.3），**不影响播放**。实测「布拉格广场」`yrc=false tlyric=true`、「想你就写信(Live)」`yrc=false tlyric=false`。解析器必须先试 YRC、**只有当 YRC 里存在"含逐字信息的行"时才采用**，否则退回 LRC。

### 1.6 请求头 / Cookie

与 MI-1 / MI-2 完全一致：`User-Agent = NetEaseHeader.UA`、`Cookie = NetEaseHeader.cookieHeader(header)`、`Referer = https://music.163.com`，`header` 只构造一次、加密 JSON 里的 `header` 与 Cookie 头必须同一份。

创建 `app/src/main/java/com/musicbox/app/lyric/LyricTimeline.kt`：

```kotlin
package com.musicbox.app.lyric

import com.musicbox.app.model.LyricData

/**
 * 一个逐字单元。YRC 的每个 `(start,dur,0)text` 就是一个 LyricWord，
 * text 可能含多个字符（也含空格）——CJK 一般一字一词，拉丁文一般一词一 Word。
 */
data class LyricWord(
    val startMs: Long,
    val durationMs: Long,
    val text: String,
) {
    val endMs: Long get() = startMs + durationMs
}

/**
 * 一行歌词。
 * words 为空 → 只有逐行时间（LRC 降级），整行高亮；
 * words 非空 → 可做逐字填充动画。
 */
data class LyricLine(
    val startMs: Long,
    val durationMs: Long,
    val text: String,
    val words: List<LyricWord> = emptyList(),
    val translation: String? = null,
    val romaji: String? = null,
) {
    val endMs: Long get() = startMs + durationMs
}

/**
 * 整首歌的歌词时间轴。lines 按 startMs 升序、无重叠、每行 durationMs > 0。
 */
data class LyricTimeline(
    val lines: List<LyricLine>,
) {
    val isEmpty: Boolean get() = lines.isEmpty()

    /**
     * 当前位置对应的"当前行"下标。
     * - 首行开始之前 → -1（还没到第一句）
     * - 行与行之间的空隙 → 返回最近**已开始**的那一行（卡拉OK惯例：上一句保持高亮到下一句开始）
     */
    fun indexAt(positionMs: Long): Int {
        if (lines.isEmpty()) return -1
        if (positionMs < lines.first().startMs) return -1
        var low = 0
        var high = lines.size - 1
        var answer = 0
        while (low <= high) {
            val mid = (low + high) / 2
            if (lines[mid].startMs <= positionMs) {
                answer = mid
                low = mid + 1
            } else {
                high = mid - 1
            }
        }
        return answer
    }

    fun lineAt(positionMs: Long): LyricLine? = lines.getOrNull(indexAt(positionMs))
}

/**
 * 某个字（词）在给定播放位置下的"填充进度"，0f~1f。
 * 只做纯数学，供 UI 每帧调用——动画的丝滑就靠它每帧被重算。
 */
fun wordProgress(positionMs: Long, word: LyricWord): Float {
    if (positionMs <= word.startMs) return 0f
    if (positionMs >= word.endMs) return 1f
    val span = word.durationMs.coerceAtLeast(1L).toFloat()
    return ((positionMs - word.startMs).toFloat() / span).coerceIn(0f, 1f)
}

/** 未使用，仅供 LyricData 的可见性提醒：解析器入口吃的是 LyricData。 */
internal typealias RawLyric = LyricData
```

> 注意：最后那个 `typealias` 若嫌多余可删——它只是提醒 `LyricParser.parse` 的入参类型。保留或删除都不影响编译。

package com.musicbox.app.lyric

import org.junit.Assert.assertEquals
import org.junit.Assert.assertNull
import org.junit.Test

class LyricTimelineTest {

    private fun line(start: Long, dur: Long) = LyricLine(start, dur, "L$start")

    private val timeline = LyricTimeline(
        listOf(
            line(10_000, 2_000),
            line(13_000, 1_000),
            line(15_000, 3_000),
        ),
    )

    @Test
    fun `indexAt returns minus one before the first line`() {
        assertEquals(-1, timeline.indexAt(0))
        assertEquals(-1, timeline.indexAt(9_999))
    }

    @Test
    fun `indexAt returns the last line whose start has passed`() {
        assertEquals(0, timeline.indexAt(10_000))
        assertEquals(0, timeline.indexAt(12_999))
        assertEquals(1, timeline.indexAt(13_000))
        assertEquals(2, timeline.indexAt(99_999))
    }

    @Test
    fun `indexAt keeps previous line during a gap`() {
        // 14_000 落在第 1 行结束(14_000)与第 2 行开始(15_000)之间的空隙 → 仍算第 1 行
        assertEquals(1, timeline.indexAt(14_000))
        assertEquals(1, timeline.indexAt(14_999))

    fun `lineAt returns null before first line`() {
        assertNull(timeline.lineAt(0))
        assertEquals(1, timeline.lineAt(13_500)!!.startMs / 13_000)
    }

    @Test
    fun `empty timeline always returns minus one`() {
        val empty = LyricTimeline(emptyList())
        assertEquals(-1, empty.indexAt(0))
        assertEquals(-1, empty.indexAt(10_000))
        assertNull(empty.lineAt(10_000))
    }

        assertEquals(0f, wordProgress(500, word), 0.0001f)

```kotlin
package com.musicbox.app.lyric

import com.google.gson.Gson
import com.musicbox.app.model.LyricData

/**
 * 网易云歌词解析（格式规则见计划 §1.3）。
 *
 * 输入是三种格式的混排文本：
 *  A. 新版 JSON 行 : {"t":0,"c":[{"tx":"作曲: "},{"tx":"周杰伦"}]}   —— 无逐字
 *  B. 经典 YRC     : [行起始,行时长](字起始,字时长,0)字(字起始,字时长,0)字…  —— 有逐字
 *  C. 经典 LRC     : [mm:ss.xxx] 文本                              —— 无逐字
 * 解析职责全在这里，音源层只负责把原始文本搬回来（见 MusicProvider.getLyric）。
 */
object LyricParser {

    /** 译文/罗马音与主行的时间戳容差（实测相差 ±10~50ms，见 §1.4）。 */
    const val ALIGN_TOLERANCE_MS = 600L

    /** 末行没有后继行时的兜底时长。 */
    private const val TAIL_DURATION_MS = 5_000L

    /** 一行至少持续这么久，避免 next-start 与自身 start 相同时出现 0 时长。 */
    private const val MIN_LINE_MS = 200L

    private val gson = Gson()

    /** 新版 JSON 行。 */
    private data class JsonLine(val t: Long = 0L, val c: List<JsonCell>? = null)
    private data class JsonCell(val tx: String? = null)

    /** YRC 行头：[起始,时长] 或 [起始,时长,?]。 */
    private val yrcLineRegex = Regex("""^\[(\d+),(\d+)(?:,(\d+))?\](.*)$""")

    /** YRC 字头：(起始,时长) 或 (起始,时长,?) ，随后到下一个 ( 之前是文本。 */
    private val yrcWordRegex = Regex("""\((\d+),(\d+)(?:,(\d+))?\)([^()]*)""")

    /** LRC 行头：[mm:ss]、[mm:ss.x]、[mm:ss.xx]、[mm:ss.xxx]、[mm:ss:xxx]。 */
    private val lrcTagRegex = Regex("""\[(\d{1,3}):(\d{1,2})(?:[.:](\d{1,3}))?\]""")

    /** LRC 元信息标签：[by:xxx] [ti:xxx] [offset:±ms] … */
    private val metaRegex = Regex("""^\[([A-Za-z]+):(.*)]$""")

    /** 解析中间态：durationMs 为 null 表示"待用下一行起始填充"。 */
    private data class Parsed(
        var startMs: Long,
        val durationMs: Long?,
        val text: String,
        val words: List<LyricWord>,
    )

    fun parse(data: LyricData): LyricTimeline {
        // 主歌词优先 YRC；只有 YRC 里真的存在逐字行时才用它，否则退回 LRC（§1.5）
        val main = parseYrc(data.yrc)
            .takeIf { list -> list.any { it.words.isNotEmpty() } }
            ?: parseLrc(data.lrc)

        if (main.isEmpty()) return LyricTimeline(emptyList())

        val translation = parseLrc(data.translation)
        val romaji = parseLrc(data.romaji)

        val withAlignment = main.map { line ->
            line.copy(
                translation = nearestText(translation, line.startMs),
                romaji = nearestText(romaji, line.startMs),
            )
        }
        return LyricTimeline(resolveDurations(withAlignment))
    }

    // ── 格式 A + B 混排 ─────────────────────────────────────────

    private fun parseYrc(text: String?): List<Parsed> {
        if (text.isNullOrBlank()) return emptyList()
        val out = ArrayList<Parsed>()
        for (raw in text.lineSequence()) {
            val line = raw.trim()
            if (line.isEmpty()) continue
            parseJsonLine(line)?.let { out += it; continue }
            parseYrcLine(line)?.let { out += it }
        }
        return out
    }

    private fun parseJsonLine(line: String): Parsed? {
        if (!line.startsWith("{")) return null
        val dto = runCatching { gson.fromJson(line, JsonLine::class.java) }.getOrNull() ?: return null
        val text = dto.c?.mapNotNull { it.tx }?.joinToString("").orEmpty()
        if (text.isBlank()) return null
        return Parsed(dto.t, durationMs = null, text = text, words = emptyList())
    }

    private fun parseYrcLine(line: String): Parsed? {
        val match = yrcLineRegex.find(line) ?: return null
        val startMs = match.groupValues[1].toLong()
        val durationMs = match.groupValues[2].toLong()
        val words = yrcWordRegex.findAll(match.groupValues[4]).map { word ->
            LyricWord(
                startMs = word.groupValues[1].toLong(),
                durationMs = word.groupValues[2].toLong(),
                text = word.groupValues[4],
            )
        }.toList()
        if (words.isEmpty()) return null
        return Parsed(startMs, durationMs, words.joinToString("") { it.text }, words)
    }

    // ── 格式 A + C 混排 ─────────────────────────────────────────

    private fun parseLrc(text: String?): List<Parsed> {
        if (text.isNullOrBlank()) return emptyList()
        val out = ArrayList<Parsed>()
        var offsetMs = 0L

        for (raw in text.lineSequence()) {
            val line = raw.trim()
            if (line.isEmpty()) continue

            parseJsonLine(line)?.let { out += it; continue }

            val meta = metaRegex.find(line)
            if (meta != null) {
                if (meta.groupValues[1].equals("offset", ignoreCase = true)) {
                    offsetMs = meta.groupValues[2].trim().toLongOrNull() ?: 0L
                }
                continue
            }

            val tags = lrcTagRegex.findAll(line).toList()
            if (tags.isEmpty()) continue
            val content = line.substring(tags.last().range.last + 1).trim()
            if (content.isEmpty()) continue
            for (tag in tags) {
                out += Parsed(
                    startMs = tag.groupValues[1].toLong() * 60_000L +
                        tag.groupValues[2].toLong() * 1_000L +
                        fractionToMs(tag.groupValues[3]),
                    durationMs = null,
                    text = content,
                    words = emptyList(),
                )
            }
        }

        if (offsetMs == 0L) return out
        return out.map { it.also { p -> p.startMs -= offsetMs } }
    }

    private fun fractionToMs(fraction: String): Long {
        if (fraction.isEmpty()) return 0L
        return when (fraction.length) {
            1 -> fraction.toLong() * 100
            2 -> fraction.toLong() * 10
            else -> fraction.substring(0, 3).toLong()
        }
    }

    // ── 收尾 ────────────────────────────────────────────────────

    private fun resolveDurations(parsed: List<Parsed>): List<LyricLine> {
        val sorted = parsed.sortedBy { it.startMs }
        return sorted.mapIndexed { index, p ->
            val nextStart = sorted.getOrNull(index + 1)?.startMs
            val duration = p.durationMs?.takeIf { it > 0L }
                ?: nextStart?.let { it - p.startMs }
                ?: TAIL_DURATION_MS
            LyricLine(
                startMs = p.startMs,
                durationMs = duration.coerceAtLeast(MIN_LINE_MS),
                text = p.text,
                words = p.words,
            )
        }
    }

    private fun nearestText(candidates: List<Parsed>, targetMs: Long): String? {
        if (candidates.isEmpty()) return null
        var best: Parsed? = null
        var bestDelta = Long.MAX_VALUE
        for (candidate in candidates) {
            val delta = kotlin.math.abs(candidate.startMs - targetMs)
            if (delta < bestDelta) {
                bestDelta = delta
                best = candidate
            }
        }
        return if (bestDelta <= ALIGN_TOLERANCE_MS) best?.text?.takeIf { it.isNotBlank() } else null
    }
}

            val header = NetEaseHeader.build(deviceId)
            val payload = linkedMapOf<String, Any>(
                // 注意：这里是数字 id，不是取流那样的字符串 JSON 数组（实测，见计划 §1.1）
                "id" to songId,
                "cp" to false,
                "tv" to 0,
                "lv" to 0,
                "rv" to 0,
                "kv" to 0,
                // 下面三个控制是否返回 yrc/tlyric/romalrc，实测 0 即可拿到全部字段
                "yv" to 0,
                "ytv" to 0,
                "yrv" to 0,
                "e_r" to false,
                "header" to header,
            )
            val uri = LYRIC_URI
            val params = NetEaseCrypto.eapiParams(uri, gson.toJson(payload))
            val body = "params=" + URLEncoder.encode(params, "UTF-8")
            val headers = mapOf(
                "User-Agent" to NetEaseHeader.UA,
                "Cookie" to NetEaseHeader.cookieHeader(header),
                "Referer" to "https://music.163.com",
            )

            val response = transport.post(EAPI_BASE + uri.replace("/api", "/eapi"), body, headers)

            val dto = try {
                gson.fromJson(response.body, LyricRespDto::class.java)
            } catch (e: JsonSyntaxException) {
                throw SourceError.Parse("响应不是合法 JSON", e)
            } ?: throw SourceError.Parse("响应为空", null)

            if (dto.code != 200) {
                throw SourceError.Api(dto.code, null)
            }

            // 原始文本原样交给 lyric 层解析（音源不解析歌词，见设计文档 §4.2）
            Result.success(
                LyricData(
                    yrc = dto.yrc?.lyric?.takeIf { it.isNotBlank() },
                    lrc = dto.lrc?.lyric?.takeIf { it.isNotBlank() },
                    translation = dto.tlyric?.lyric?.takeIf { it.isNotBlank() },
                    romaji = dto.romalrc?.lyric?.takeIf { it.isNotBlank() },
                ),
            )
        } catch (e: SourceError) {
            Result.failure(e)
        } catch (e: IOException) {
            Result.failure(SourceError.Network(e))
        }
    }
```

```kotlin
package com.musicbox.app.lyric

/**
 * 歌词进程内缓存。纯 JVM 实现（LinkedHashMap + accessOrder），不依赖 Android，可单测。
 *
 * 只存**已解析**的 LyricTimeline：解析是一次性 CPU 开销，缓存解析结果可省去来回切歌的重复解析。
 * 歌词不像取流地址那样会过期（同一首歌的歌词基本不变），因此不设 TTL，只做容量淘汰。
 * 磁盘缓存留到 MI-4。
 */
class LyricCache(private val maxEntries: Int = 20) {

    // accessOrder = true：get 把条目挪到队尾，队首即「最久未使用」
    private val entries = LinkedHashMap<Long, LyricTimeline>(16, 0.75f, true)

    fun get(songId: Long): LyricTimeline? = synchronized(entries) { entries[songId] }

    fun put(songId: Long, timeline: LyricTimeline) = synchronized(entries) {
        entries[songId] = timeline
        while (entries.size > maxEntries) {
            entries.remove(entries.keys.first())
        }
    }

    fun size(): Int = synchronized(entries) { entries.size }
}

/**
 * 进程内共享实例。UI 与（未来的）预取共用一份，避免重复请求。
 * 单测请自行 new LyricCache()，不要用这个共享实例。
 */
internal val sharedLyricCache = LyricCache()
```

import androidx.lifecycle.viewModelScope

import com.musicbox.app.lyric.LyricTimeline
import com.musicbox.app.lyric.sharedLyricCache
import com.musicbox.app.source.MusicProvider
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.Job
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.flow.asStateFlow
import kotlinx.coroutines.launch
import kotlinx.coroutines.withContext

/** 歌词页的四种终态 + 两种中间态。 */
sealed interface LyricUiState {
    /** 还没选歌。 */
    data object Idle : LyricUiState

    /** 正在拉取。 */
    data object Loading : LyricUiState

    /** 拿到并解析成功。 */
    data class Ready(val timeline: LyricTimeline) : LyricUiState

    /** 没有歌词 / 纯音乐（接口成功但无内容）。 */
    data object Empty : LyricUiState

    /** 拉取失败。UI 一律显示"暂无歌词"，绝不影响播放（设计文档 §9）。 */
    data object Failed : LyricUiState
}

/**
 * 歌词状态机：切歌 → 拉取 → 解析 → Ready/Empty/Failed。
 * 失败的兜底是 Empty/Failed 文案，**不影响播放**——歌词是可选层。
 */
class LyricViewModel(
    private val provider: MusicProvider,
    private val cache: com.musicbox.app.lyric.LyricCache = sharedLyricCache,
) : ViewModel() {

    private val _state = MutableStateFlow<LyricUiState>(LyricUiState.Idle)
    val state: StateFlow<LyricUiState> = _state.asStateFlow()

    /** 译文 / 罗马音开关。MI-3 用内存态，MI-4 落 DataStore。 */
    private val _showTranslation = MutableStateFlow(true)
    val showTranslation: StateFlow<Boolean> = _showTranslation.asStateFlow()

    private val _showRomaji = MutableStateFlow(false)
    val showRomaji: StateFlow<Boolean> = _showRomaji.asStateFlow()

    private var loadedSongId: Long? = null
    private var job: Job? = null

    fun toggleTranslation() {
        _showTranslation.value = !_showTranslation.value
    }

    fun toggleRomaji() {
        _showRomaji.value = !_showRomaji.value
    }

    /** 切歌时调用。同一首重复调用直接忽略；null 表示无当前歌 → Idle。 */
    fun load(songId: Long?) {
        if (songId == null) {
            job?.cancel()
            loadedSongId = null
            _state.value = LyricUiState.Idle
            return
        }
        if (songId == loadedSongId) return
        loadedSongId = songId
        job?.cancel()

        cache.get(songId)?.let {
            _state.value = toReady(it)
            return
        }

        _state.value = LyricUiState.Loading
        job = viewModelScope.launch {
            val data = provider.getLyric(songId).getOrNull()
            if (loadedSongId != songId) return@launch
            if (data == null) {
                _state.value = LyricUiState.Failed
                return@launch
            }
            val timeline = withContext(Dispatchers.Default) { LyricParser.parse(data) }
            if (loadedSongId != songId) return@launch
            cache.put(songId, timeline)
            _state.value = toReady(timeline)
        }
    }

    private fun toReady(timeline: LyricTimeline): LyricUiState =
        if (timeline.isEmpty) LyricUiState.Empty else LyricUiState.Ready(timeline)
}

package com.musicbox.app.ui.lyric

import androidx.compose.runtime.Composable
import androidx.compose.runtime.LaunchedEffect
import androidx.compose.runtime.State
import androidx.compose.runtime.mutableLongStateOf
import androidx.compose.runtime.remember
import androidx.compose.runtime.withFrameNanos
import com.musicbox.app.player.PositionSource

/**
 * 逐帧时钟（设计文档 §5.2 的核心决策）。
 *
 * 每帧用 withFrameNanos 唤醒一次，读一次 ExoPlayer 的真实播放位置（毫秒精度），
 * 据此驱动逐字动画的插值。**绝不**用播放器的状态回调（约 4~10Hz）——那必然阶跃、顿挫。
 *
 * 暂停时位置恒定，而 Compose 的 MutableState 用结构相等短路无效化，
 * 因此写入同值不会触发重组合——不必额外判断 isPlaying。
 */
@Composable
internal fun rememberFramePosition(source: PositionSource): State<Long> {
    val position = remember { mutableLongStateOf(source.positionMs()) }
    LaunchedEffect(source) {
        while (true) {
            withFrameNanos {
                position.longValue = source.positionMs()
            }
        }
    }
    return position
}

private fun LyricLineRow(
    line: LyricLine,
    isActive: Boolean,
    positionMs: Long,
    showTranslation: Boolean,
    showRomaji: Boolean,
    onClick: () -> Unit,
) {
    val onSurface = MaterialTheme.colorScheme.onSurface
    val dim = MaterialTheme.colorScheme.onSurfaceVariant.copy(alpha = 0.40f)

    // 当前行的"已唱"部分用主题色，未唱部分用半透明 onSurface；非当前行整体暗
    val baseColor = if (isActive) onSurface.copy(alpha = 0.30f) else dim
    val fillColor = if (isActive) MaterialTheme.colorScheme.primary else dim

    val alpha by animateFloatAsState(targetValue = if (isActive) 1f else 0.85f, label = "lineAlpha")
    val style: TextStyle = if (isActive) {
        MaterialTheme.typography.titleLarge.copy(fontSize = 22.sp, lineHeight = 32.sp)
    } else {
        MaterialTheme.typography.bodyLarge.copy(fontSize = 17.sp, lineHeight = 26.sp)
    }

    Column(
        modifier = Modifier
            .fillMaxWidth()
            .clickable(onClick = onClick)
            .padding(vertical = 10.dp),
    ) {
        if (line.words.isNotEmpty()) {
            FlowRow(horizontalArrangement = Arrangement.Start) {
                line.words.forEach { word ->
                    KaraokeWord(
                        word = word,
                        positionMs = positionMs,
                        baseColor = baseColor,
                        fillColor = fillColor,
                        style = style,
                        alpha = alpha,
                    )
                }
            }
        } else {
            // LRC 降级：整行高亮（设计文档 §5.3）
            Text(
                text = line.text,
                style = style,
                color = if (isActive) onSurface else dim,
            )
        }

        if (showTranslation && !line.translation.isNullOrBlank()) {
            Text(
                text = line.translation!!,
                style = MaterialTheme.typography.bodySmall,
                color = MaterialTheme.colorScheme.onSurfaceVariant.copy(alpha = if (isActive) 0.9f else 0.5f),
                modifier = Modifier.padding(top = 2.dp),
            )
        }
        if (showRomaji && !line.romaji.isNullOrBlank()) {
            Text(
                text = line.romaji!!,
                style = MaterialTheme.typography.labelSmall,
                color = MaterialTheme.colorScheme.onSurfaceVariant.copy(alpha = if (isActive) 0.75f else 0.4f),
                modifier = Modifier.padding(top = 2.dp),
            )
        }
    }
}

/**
 * 一个词的逐字填充：暗底 + 亮面（亮面按进度裁剪）。
 * progress 每帧由调用方传入的 positionMs 重算（见 wordProgress）。
 */
@Composable
private fun KaraokeWord(
    word: LyricWord,
    positionMs: Long,
    baseColor: Color,
    fillColor: Color,
    style: TextStyle,
    alpha: Float,
) {
    val progress = wordProgress(positionMs, word)
    Box {
        Text(
            text = word.text,
            style = style,
            color = baseColor.copy(alpha = baseColor.alpha * alpha),
            softWrap = false,
        )
        if (progress > 0f) {
            Text(
                text = word.text,
                style = style,
                color = fillColor.copy(alpha = fillColor.alpha * alpha),
                softWrap = false,
                modifier = Modifier.drawWithContent {
                    clipRect(right = size.width * progress) {
                        this@drawWithContent.drawContent()
                    }
                },
            )
        }
    }
}
